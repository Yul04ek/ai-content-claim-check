Tallowick

See where your coding agents spend their tokens.

Tallowick reads the session logs of your coding agents and shows which tasks, repositories and people the spend went to.

The problem

Engineering teams now run several coding agents side by side. The bill arrives as one number per vendor. Nobody can say which work it paid for.

When a developer reaches the token limit, the request for more is a guess. When an agent repeats the same failed fix twenty times, the team finds out from the invoice.

What Tallowick does

Measure

Token spend is assigned to the task, the repository and the pull request it belongs to.

Explain

A weekly digest lists the five most expensive tasks and what the agent did in each.

Alert

A message is sent when an agent loops on the same error or passes a spend limit you set.

Who it is for

Tallowick is built for engineering teams of 20 to 200 developers that use two or more coding agents. It is probably not the right fit for a team that uses a single agent or has fewer than ten developers.

About Tallowick

A letter from the founder, 20 October 2026

Tallowick was founded in February 2026. We are four people: two engineers, a designer and me.

I spent eight years on platform teams. My job was to make tools that other engineers could trust without thinking about them. Coding agents broke that. They do a lot of work that nobody sees, and the only trace is the bill.

We started with a script that read our own agent logs. Three teams asked for it in the first month. Today we have three pilot customers and no revenue.

In September 2026 we joined the Northpier Ventures Autumn 2026 cohort. The programme ends in December. After it we plan to raise our first outside round.

None of us has a finance background. Our numbers live in one spreadsheet that I update on Sundays. We have not written a pitch deck yet.

The next three months are about one thing: turning three pilots into a product that a team can start using without a call with us.

Thank you for reading.

Maren Oduya, founder and CEO
